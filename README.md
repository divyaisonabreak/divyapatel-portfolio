# ReactFolioSite

This is a portfolio website built with React, Vite, and Express.

## Prerequisites

- Node.js (version 20 or higher recommended)
- npm (comes with Node.js)

## Setup

1.  Open a terminal in the project directory.
2.  Install dependencies:
    ```powershell
    npm install
    ```

## Running the Application

To run the application in development mode (with a mock database):

**Option 1: Using the PowerShell script (Recommended for Windows)**

```powershell
.\run_dev.ps1
```

**Option 2: Using npm directly**

If you cannot use the PowerShell script, you can run:

```bash
npm run dev
```

*Note: The `run_dev.ps1` script automatically sets up a mock database URL which is required for the app to run correctly in development.*

The application will start on [http://localhost:5000](http://localhost:5000).
